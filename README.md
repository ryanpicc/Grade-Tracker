# Grade Tracker

A Java-based application for tracking student grades and practicing fundamental software development concepts.

## About the Project

Grade Tracker is a learning project that I am building as I develop my Java programming skills. The application will be expanded over time as I learn new Java concepts and software engineering practices.

* Practice core Java programming concepts

* Gain experience building a complete project

* Gradually add new features as my programming skills develop
